# FP&A Intelligence Platform

An automated financial analysis platform for major US banks, built on free SEC EDGAR data.

## What it does
- Pulls quarterly financial data for US banks from the SEC EDGAR API
- Cleans and reconciles the data into a PostgreSQL database
- Runs ratio and variance analysis with automatic flags
- Forecasts the next 4 quarters with scenarios
- Shows results in a Streamlit app and Power BI
- Drafts management commentary using an LLM

## Tech stack
Python, pandas, PostgreSQL, SQL, Streamlit, Power BI, Git
